⚡ אופן פעולה

שכבה 7 היא השכבה העליונה ביותר במודל OSI/TCP-IP. זוהי השכבה היחידה שאיתה המשתמש או התוכנות שלו (הדפדפן, תוכנת המייל, המשחק) באים במגע ישיר. תפקידה לספק שירותי רשת לאפליקציות, לקבל את המידע הגולמי (Payload) ולהעביר אותו כלפי מטה בצינור הפרוטוקולים לצורך אריזה ומשלוח.

📖 פרוטוקול DNS (Domain Name System)

⚡ ספר הטלפונים של האינטרנט

בני אדם מעולים בלזכור שמות כמו google.com, אבל מחשבים ונתבים עובדים רק עם כתובות IP במספרים (כמו 142.250.185.78). פרוטוקול DNS פותר את הבעיה: הוא מקבל את השם שרשמתם בדפדפן ומחזיר למחשב שלכם את כתובת ה-IP המדויקת של השרת!

🔒 HTTP / HTTPS - הפרוטוקולים של ה-Web

⚡ איך אנחנו רואים אתרי אינטרנט?

פרוטוקול HTTP אחראי על העברת דפי אינטרנט, תמונות, וידאו ונתוני JSON משרת ה-Web אל הדפדפן שלכם. הוא עובד במודל של בקשה ותשובה (Request-Response). גרסתו המאובטחת, HTTPS, מוסיפה שכבת הצפנה חזקה (TLS/SSL) שמגנה על הסיסמאות והאשראי שלכם מפני הופכים במצע (Sniffers)!

⚙️ פרוטוקול DHCP - חלוקת IP אוטומטית

⚡ איך המחשב מקבל רשת בשנייה הראשונה?

כאשר מחשב או טלפון מתחבר ל-Wi-Fi, אין לו עדיין כתובת IP! פרוטוקול DHCP הוא השירות בשכבה 7 שמעניק לו כתובת IP, מסיכת רשת (Subnet Mask), שער מחדש (Default Gateway) וכתובות שרתי DNS באופן אוטומטי לחלוטין!

🛠️ ארבעת שלבי תהליך D.O.R.A

1. Discover (D)הלקוח צועק: "מישהו פה שרת DHCP?" (Broadcast)
2. Offer (O)השרת עונה: "יש לי כתובת IP להציע לך!"
3. Request (R)הלקוח משיב: "מעולה! אני אשמח לקבל את הכתובת"
4. Acknowledge (A)השרת מאשר: "סגור! הכתובת שלך לשעתיים"

⚠️ מה קורה כששרת ה-DHCP נכשל? - מנגנון APIPA

כאשר מחשב שמוגדר לקבל כתובת אוטומטית שולח הודעת Discover אך אינו מקבל מענה משרת DHCP (בגלל שרת כבוי, נתק ברשת או בעיית כבל), מופעל מנגנון החירום APIPA (Automatic Private IP Addressing)[span_1](start_span)[span_1](end_span).

טווח הכתובות 169.254.0.1 עד 169.254.255.254
מסיכת רשת 255.255.0.0 (או בסימון /16)
יכולת תקשורת רשת מקומית (LAN) בלבד! ללא גישה לאינטרנט
פקודת פתרון תקלותipconfig /renew בשרת התקני

💡 תסמין זיהוי בשטח: ראיתם כתובת המתחילה ב-169.254.x.x במחשב? זהו ה"דגל האדום" לכך שהמחשב אינו מצליח לדבר עם שרת ה-DHCP! ברגע שזה קורה, המחשב יוכל לדבר רק עם מחשבים ששוכנים לידו באותה רשת פיזית, אך לא יוכל לעבור דרך הנתב (רשת ללא Default Gateway).
